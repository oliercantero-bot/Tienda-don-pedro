# 🛒 Tienda Don Pedro

Programa en Python para llevar el control del inventario de una tienda de barrio en Itagüí.
Lee los productos y sus precios desde un archivo de texto, los lista y calcula el valor total del inventario.
Además, el proyecto guarda los clientes frecuentes y las ventas del día de Don Pedro.

## Productos

| Producto    | Precio  |
|-------------|--------:|
| Leche 1L    |  $4.500 |
| Pan tajado  |  $6.500 |
| Huevos x12  | $14.000 |
| Café 500g   | $18.000 |
| Panela      |  $3.500 |
| Arroz 1kg   |  $4.500 |
